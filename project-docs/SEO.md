# SEO

This document outlines the Search Engine Optimization (SEO) strategy for the Fixamigo client application.

## Metadata

The application uses Next.js's Metadata API to manage SEO-related metadata for each page. The metadata is defined in the `lib/seo` directory and is organized by page or page type.

### Static Metadata

For static pages like the homepage, about page, and contact page, the metadata is defined in separate files (e.g., `homepageMetadata.ts`, `aboutMetadata.ts`). These files export a `Metadata` object that contains the title, description, keywords, and other SEO-related information for the page.

### Dynamic Metadata

For dynamic pages like brand pages, device pages, and city pages, the application uses functions to generate the metadata dynamically. These functions take the dynamic parameters (e.g., brand slug, device slug, city slug) as input and return a `Metadata` object.

- **`generateCategoryMetadata(category: string)`**: Generates metadata for a specific repair category.
- **`generateCityMetadata(city: string)`**: Generates metadata for a specific city.
- **`generateDeviceMetadata(brand: string, device: IDevice)`**: Generates metadata for a specific device.
- **`generateListBrandMetadata(brand: string)`**: Generates metadata for a specific brand listing page.

## Sitemap

The application generates a sitemap at `/sitemap.xml` to help search engines discover and index the pages. The sitemap is generated by the `app/sitemap.ts` file.

The sitemap includes all the public-facing pages, including:

- Static pages (homepage, repair, support-request)
- City pages
- Repair category pages
- Brand pages
- Device pages

The sitemap also specifies the change frequency and priority for each page to guide search engines on how often to crawl the pages.

## robots.txt

The application has a `robots.txt` file at the root of the site to control how search engines crawl and index the site. The `robots.txt` file is generated by the `app/robots.ts` file.

The `robots.txt` file:

- Allows search engines to crawl all the public-facing pages.
- Disallows search engines from crawling private pages (e.g., cart, my-services, checkout), API routes, and other non-public resources.
- Specifies different crawl delays for different search engines.
- Blocks known bad bots and scrapers.

## Structured Data

The application uses JSON-LD to provide structured data to search engines. This helps search engines understand the content of the pages and display rich snippets in the search results.

The structured data is included in the metadata for each page and is generated using the `Metadata` object from Next.js.
